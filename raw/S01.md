# S01 — Test-Enhanced Learning: Taking Memory Tests Improves Long-Term Retention

- 作者：Roediger & Karpicke
- 年份：2006
- 類型：實驗研究
- DOI：https://doi.org/10.1111/j.1467-9280.2006.01693.x
- 來源網址：https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/
- 讀取範圍：官方期刊／PubMed 公開摘要及可取得之研究摘要；未宣稱逐頁閱讀所有付費全文。

## 可引用的研究結論
兩項以文章材料進行的實驗：延遲兩天或一週時，先前的提取測驗比重讀帶來較佳保留；五分鐘後測驗則可能呈現相反結果。

## 解讀限制
提取練習效果受測驗延遲時間與材料等條件影響；不能解讀成每次測驗都優於閱讀。
