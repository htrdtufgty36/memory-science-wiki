# 記憶科學 LLM Wiki 專案

## 開始使用
1. 打開 `wiki/knowledge.md` 閱讀 Wiki。
2. 使用瀏覽器開啟 `slides/index.html`，點「上一頁／下一頁」或左右方向鍵。
3. 查看 `wiki/slide_evidence_map.md` 逐頁證據。
4. 查看 `logs/validation.json`、`logs/workflow_and_reflection.md` 了解真實檢查。

## 公開連結
目前是可下載的本機檔案，尚未部署為公開 Wiki / HTML 網址。若需繳交 URL，可將整個資料夾上傳 GitHub 儲存庫並開啟 GitHub Pages，將 `slides/index.html` 設為對外入口。
